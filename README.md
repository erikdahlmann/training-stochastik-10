# Mathe-Training Stochastik · Klasse 10

Interaktive Übungsseite zur Vorbereitung auf die erste Klassenarbeit: Häufigkeiten,
mehrstufige Baumdiagramme ohne Zurücklegen, Vierfeldertafel, bedingte Wahrscheinlichkeit
sowie das kritische Beurteilen statistischer Grafiken.

Sieben Themen mit je drei Aufgabenversionen, Selbstkontrolle und Lösungsweg.
Der Fortschritt bleibt lokal im Browser gespeichert.

Online: https://erikdahlmann.github.io/training-stochastik-10/
